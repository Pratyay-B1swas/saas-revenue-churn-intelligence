# 📊 Micro-SaaS Product & Revenue Intelligence Engine

An end-to-end Data Analytics & Machine Learning project built in Google Colab to predict customer churn risk, quantify potential Monthly Recurring Revenue (MRR) loss, and generate automated retention strategies.

![Dashboard Preview](fixed_dashboard.png)

---

## 💡 Key Features
- **Predictive Churn Risk Scoring:** Calculates granular 0–100% risk scores for every active account using Random Forest.
- **Financial Exposure Quantification:** Evaluates potential `$ MRR Loss at Risk` per customer to prioritize retention efforts.
- **Automated Recommendation Engine:** Categorizes accounts into targeted action strategies based on LTV and engagement behavior.

---

## 🛠️ Tech Stack & Methods
- **Language:** Python
- **Data Engineering:** Pandas, NumPy (Data merging, aggregation, feature engineering)
- **Machine Learning:** Scikit-Learn (Random Forest Classifier, probability evaluation)
- **Data Visualization:** Matplotlib, Seaborn (Multi-panel executive dashboard)

---

## 📂 Repository Structure
- `microsaas_product_and_revenue_analytics.ipynb` -> Main Google Colab Notebook
- `fixed_dashboard.png` -> High-resolution multi-panel visual report
- `final_saas_product_analytics.csv` -> Processed dataset with churn scores & recommendations
- Raw CSV datasets (`customers.csv`, `revenue.csv`, `subscriptions.csv`, `user_activity.csv`)
